# Logos des intégrations

Marques Salesforce, Slack, Microsoft Teams, Discord, n8n et Zapier, utilisées uniquement pour signaler les intégrations KayrosLab (usage nominatif). Tracés issus de [Simple Icons](https://simpleicons.org) (CC0 1.0) — Salesforce, Slack et Microsoft Teams depuis simple-icons 9.21.0, les autres depuis 16.34.0 — colorisés aux couleurs officielles des marques. Les marques restent la propriété de leurs détenteurs.

Les pages `index.html` / `index.fr.html` embarquent les mêmes tracés en sprite SVG inline (`<symbol id="logo-…">`), sans requête externe.
