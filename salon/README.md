# Salon

Cercles littéraires et philosophiques. Un service KayrosLab, pas la console.

- Spécimen : `index.html` (GitHub Pages `/salon/`)
- Moteur : `src/` (agents, cercles, Gutenberg, PDF/TXT, i18n, export)
- Mémoire compilée : `scripts/openkb_*.mjs` (pipeline OpenKB) — voir [docs/SALON-OPENKB.md](../docs/SALON-OPENKB.md)
- Qualité de parole et publication : `scripts/enrich_catalog.mjs`, `scripts/harvest_corpus.mjs`,
  `scripts/speech_eval.mjs`, `scripts/publish_gate.mjs` — voir [docs/SALON-QUALITE.md](../docs/SALON-QUALITE.md)
- Rust : `../crates/salon-core`
