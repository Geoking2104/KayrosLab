Architecture

Agent = Model + Harness

Every agent in KayrosLab follows the LangChain pattern: a model providing reasoning, wrapped in a harness of tools, prompts, and middleware that shapes its behavior.

Agent = Model + Tools + Prompt + Middleware

Model

Swap between Claude, GPT, Gemini, DeepSeek, or local Ollama. Each agent picks the best model for its role.

Tools

Function-calling registry: agents call ki_scorer, search_competitors, risk_assessor and more.

Prompt

Each agent has a specialized system prompt defining its role, constraints, and output format.

Middleware

Fault tolerance, guardrails, human-in-the-loop gates, and context management between sessions.
