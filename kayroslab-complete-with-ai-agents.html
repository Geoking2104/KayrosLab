Architecture

Agent = Model + Harness

Every agent in KayrosLab follows the LangChain pattern: a model providing reasoning, wrapped in a harness of tools, prompts, and middleware.

Agent = Model + Tools + Prompt + Middleware

Model

Claude, GPT, Gemini, DeepSeek or local Ollama.

Tools

ki_scorer, search_competitors, ontological_mapper…

Prompt

Specialized system prompts per agent role.

Middleware

Guardrails + human-in-the-loop gates.
